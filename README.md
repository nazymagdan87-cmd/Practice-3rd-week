# Премьеры 2026
 
Учебный проект по дисциплине «Основы бэкэнд-программирования».
Практическая работа № 2.
 
## Что делает
 
Страница получает данные из файла `data.json` и формирует
из них список карточек фильмов.
 
## Состав файлов
 
- `index.html` — разметка и контейнеры состояний
- `style.css` — оформление
- `script.js` — получение данных и формирование карточек
- `data.json` — данные, шесть фильмов
 
## Обработанные состояния
 
1. Загрузка — показывается до получения ответа
2. Ошибка — при недоступности файла, с кнопкой повтора
3. Пусто — если массив пришёл пустым
4. Данные — список карточек
 
## Как запустить
 
Открыть папку в Visual Studio Code и нажать Go Live.
Открывать index.html двойным щелчком нельзя: запрос
к локальному файлу будет заблокирован браузером.
